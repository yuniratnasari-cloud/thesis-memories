# Security Policy

## Scope

This policy applies to Thesis Memories. The MVP stores diary data, raw photos,
and final photos locally in the browser. IndexedDB is specified for photos and
diary data; `localStorage` is limited to lightweight preferences. No backend,
account, cloud synchronization, or server photo upload is approved or assumed.

## Reporting a vulnerability

**Private security reporting channel: PENDING PM APPROVAL.** No reporting email,
individual contact, or monitored private channel is designated by this policy.
Do not assume that a public issue or this repository is monitored for security
reports.

The Project Manager/repository owner must approve and publish a private
reporting channel before public release. Until then, do not post credentials,
private diary data/photos, or actionable details of an unremediated
vulnerability publicly. If a report must be raised before a private channel is
available, request a private contact path from the Project Manager through an
already approved project communication channel without including sensitive
details.

## Response and disclosure

Response-time commitments, supported versions, severity handling, and
coordinated disclosure timelines are **PENDING PM APPROVAL**. The project
maintainers should acknowledge and assess reports privately, coordinate
remediation, and agree on disclosure timing where practical. Do not publicly
disclose an unremediated issue or another person's private data.

## Security updates

No supported-release or advisory process has been established. The
Project Manager/repository owner must approve the reporting channel and
response process before public deployment.
